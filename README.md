# 🤖 Workly

### Aplicación móvil de comunicación y colaboración empresarial

Workly es una aplicación Android que desarrollé como proyecto académico de Ingeniería en Informática.

Su objetivo es facilitar la comunicación, la organización y el trabajo colaborativo dentro de una empresa, reuniendo distintas herramientas en una sola aplicación.

## 📱 Funcionalidades

- **Mensajes:** chat general para usuarios registrados.
- **Reuniones:** creación y consulta de reuniones.
- **Documentos:** sección para organizar información de trabajo.
- **Correo electrónico:** acceso a funciones de correo.
- **Sensores ambientales:** simulación de temperatura, humedad y luminosidad.
- **Análisis de rendimiento:** indicadores y visualización de registros ambientales.

## 🛠️ Tecnologías

- HTML5, CSS3 y JavaScript
- Apache Cordova
- Firebase Authentication
- Cloud Firestore
- Android
- Visual Studio Code

## 🤖 Wily

Wily es el robot que representa la identidad visual de Workly y le da una apariencia moderna y amigable.
